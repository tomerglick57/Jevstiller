# Jevstiller brand assets

The mark is a drop within a drop: the large drop is Jev, the small one cut out of it is the local model,
the essence distilled from the whole. Every shape is a plain SVG path (the wordmark is outlined from Ubuntu Medium),
so nothing depends on installed fonts.

| File | Use |
| --- | --- |
| `jevstiller-logo.svg` / `.png` | Horizontal lockup (mark + wordmark) on light backgrounds |
| `jevstiller-logo-dark.svg` | Same lockup for dark backgrounds |
| `jevstiller-mark.svg`, `jevstiller-mark-dark.svg` | Mark only, light / dark backgrounds |
| `jevstiller-icon.svg` / `-512.png` | White mark on a teal rounded square: favicon, avatars, app icons |

Colours: teal `#137572` on light backgrounds, `#3ec4bd` on dark ones (the website's accent colours).
The website header and favicon are generated from these same files (`website/src/assets`, `website/public/favicon.svg`).
